# global-noteskins
Noteskins from SM 3.9, 4, and 5 turned into global noteskins for Etterna and Project OutFox

## pro
Originally by xXChaosMasterXx (Early Pump It Up Pro noteskin) for SM4

What has done by me so far:
- Added 192nd note support (in the original noteskin, 192nd notes are completely invisible)
- Added lift graphics
- Added support for dance, smx, and techno (non-diagonal PIU arrows)
- Set the holds to flip in reverse, since they didn't in the original noteskin
- EZ2 support coming soon once I can figure out how to make the hand notes align correctly
